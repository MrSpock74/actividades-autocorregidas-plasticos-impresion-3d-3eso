Google Apps Script · Google Classroom

Actividades interactivas que se corrigen solas

Una aplicación para que tu alumnado haga actividades en línea, reciba su nota al momento y la calificación llegue a Classroom como borrador. Tú la revisas y la publicas.

Qué hace

10 tipos de pregunta

Test, verdadero/falso, respuesta múltiple, numérica, completar, relacionar, clasificar, ordenar, rotular una imagen y respuesta escrita.

Corrección en el servidor

Las soluciones nunca llegan al navegador del alumnado y las opciones se barajan en cada intento.

Respuestas escritas

Se corrigen por palabras clave, toleran faltas leves y negaciones, y tú puedes ajustar la nota a mano.

Nota a Classroom

La nota llega como borrador de calificación y los resultados quedan también en una hoja de cálculo tuya.

Intentos configurables

Decide cuántos intentos hay y si cuenta el último o el mejor. El alumnado puede repetir o ver las soluciones.

Panel del profesorado

Crea las tareas, consulta resultados, reabre intentos y reenvía notas desde una sola pantalla.

Cómo instalarla

Solo hay que hacerlo una vez. No necesitas saber programar: se trata de copiar y pegar.

  1. Descarga los archivos del repositorio (botón verde Code → Download ZIP en GitHub).
  2. Entra en script.google.com y crea un Nuevo proyecto.
  3. Crea los archivos con los mismos nombres (Code, Motor, Banco, Imagenes, Index, Panel) y pega el contenido de cada uno.
  4. En Code.gs, cambia el correo de PROFES por el tuyo y ajusta las clases y los intentos.
  5. Añade el servicio Google Classroom API y ejecuta una vez la función autorizar.
  6. Pulsa Implementar → Nueva implementación → Aplicación web y copia la dirección que termina en /exec.
  7. Abre esa dirección añadiendo ?page=panel, pega los enlaces de tus clases y crea las tareas en Classroom.

La explicación completa, con los requisitos y las limitaciones, está en el README del repositorio. Necesitas una cuenta de Google Workspace for Education con acceso a la API de Classroom; algunos centros la tienen restringida.

Usarla con otro contenido

La versión de ejemplo trabaja Plásticos e impresión 3D (Tecnología y Digitalización, 3º ESO), pero está pensada para cualquier materia. Para cambiar el contenido solo hay que editar el archivo Banco.gs (preguntas, criterios y explicaciones) y las imágenes. El resto de la aplicación no se toca.

Protección de datos

El código no contiene datos de alumnado. Los intentos y las notas se guardan en una hoja de cálculo que la aplicación crea en tu Drive, no en ningún servidor externo.
